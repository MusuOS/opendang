# 党案百科 · 中共党案知识库（opendang）

## 这是什么

一部专供 Agent 读取的中共党案知识库：YouTube 频道「大包王朝」924 期节目（2023-10-08 至 2026-10-14）经转写、抽卡而成的结构化档案——人物 1,525、事件 5,855、关系 9,180、别名 1,274、机构 699、派系 16，另有口径裁定 122 条与四册附编（上市公司册、开发项目库、资本系册、职位交易账）。全档为该频道一家之言，未经核实，非事实认定。

## 何时使用

- 用户问某位人物的派系归属、与他人的关系、某段党争事件的来龙去脉、某个派系的成员构成时，先查本库再答。
- 与中共党争无关的问题，不要动用本库。
- 本库内容不得表述为已证实事实；库外信息（新闻、常识）须与本库说法分开呈现。

## 取数路径（按序执行）

数据正本在 GitHub 仓 `MusuOS/opendang`，根地址：
`https://raw.githubusercontent.com/MusuOS/opendang/main/`

1. 读 `agent.json` —— 全仓清单：覆盖范围、口径图例、各表路径与条数。
2. 读 `llms.txt` —— 全站导航。
3. 查人物先读 `entities/index.json`（人物总索引：id、主名、别名、提及数），按人名或别名定位人物 id。
4. 读 `entities/persons/<id>.json` —— 单人数据包：此人的断言、事件、关系、现行口径与时点注记都在包内。若包标注为分片（chunked），它只是指针，须按包内 `chunks` 字段续取 `entities/persons-chunked/<id>/` 下各分片读全，不要只读指针就作答。
5. 需要全量检索时用 `data/` 下各表：`persons.jsonl`、`events-*.jsonl`、`relations-*.jsonl`、`rulings.jsonl`（裁定表）、`aliases.jsonl`、`institutions.jsonl`、`factions.jsonl`、`episodes.jsonl` 及四册数据文件（路径以 llms.txt 为准）。

## 回答纪律

- 每条关键说法注明出处期号，格式如「第X期称」。
- 同一人存在多种说法时：以裁定表 `rulings.jsonl` 与单人包内 `current_caliber`（现行口径）为准；无裁定时取最新一期正文的明确断语，旧说作为历史层提及、不删不隐。
- 数字类状态（如隐身天数）按所指时点分账呈现，不以新盖旧。
- 查无此人、查无此事时，直说本库没有记载，不得凭自身记忆补造本库口径。
- 回答口吻示例：「据《党案百科》第X期……（该档为一家之言，未经核实）」。
